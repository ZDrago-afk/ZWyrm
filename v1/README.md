# 🛡️ ZWyrm AntiVirus v1.0

![ZWyrm AntiVirus](https://img.shields.io/badge/ZWyrm-AntiVirus-blue)
![Python](https://img.shields.io/badge/Python-3.7+-green)
![Platform](https://img.shields.io/badge/Platform-Linux-lightgrey)
![License](https://img.shields.io/badge/License-MIT-orange)

**ZWyrm** (pronounced *"worm"*) is a lightweight **Python-based antivirus and security framework for Linux systems**.

It provides tools for:

- malware detection
- file system scanning
- real-time monitoring
- quarantine management
- automatic signature updates

ZWyrm is designed to be **simple, extensible, and resource-efficient**, making it suitable for learning cybersecurity concepts and building security tools.

## 📁 Project Structure

| Path | Description |
|-----|-------------|
| `cli/` | Command-line interface modules for user interaction |
| `core/` | Core antivirus engine (scanner, quarantine system) |
| `database/` | Malware signature databases and update system |
| `logs/` | Log files generated by scans and system events |
| `modules/` | Optional modules such as real-time protection |
| `utils/` | Utility functions (configuration loader, logger, helpers) |
| `config.yaml` | Main configuration file |
| `install.sh` | Automated installation script |
| `requirements.txt` | Python dependency list |
| `zwyrm.py` | Main entry point for the ZWyrm application |

## 🚀 Features

ZWyrm provides several security capabilities designed for Linux environments:

### 🔍 Malware Scanning
- Scan **individual files**
- Scan **entire directories**
- Perform **full system scans**

### ⚡ Multiple Scan Modes
- **Quick Scan** – checks common malware locations
- **Deep Scan** – more detailed scanning
- **Full System Scan** – scans entire filesystem

### 🛡️ Real-Time Protection
- Optional real-time monitoring using `pyinotify`
- Detects suspicious file creation or modification events

### 📦 Quarantine System
- Isolates detected threats safely
- Restore or permanently delete quarantined files

### 🔄 Automatic Signature Updates
- Update malware definitions from the signature database

### 📊 Logging System
- Detailed logs for scanning and quarantine operations

### ⚙️ Configurable
- Modify system behavior via `config.yaml`

### 🧩 Modular Design
- Easy to extend with additional security modules

## 📋 Requirements

Before installing ZWyrm, ensure your system has:

- **Python 3.7 or newer**
- Linux operating system
  - Ubuntu
  - Debian
  - Fedora
  - CentOS

Optional dependency:

- `pyinotify` (required for real-time protection)

## 🔧 Installation

### Quick Install (Recommended)

Clone the repository:

git clone https://github.com/ZDrago-afk/ZWyrm.git

cd ZWyrm

Run the installation script:

chmod +x install.sh
./install.sh

pip install -r requirements.txt
chmod +x zwyrm.py

sudo ln -s $(pwd)/zwyrm.py /usr/local/bin/zwyrm

## 🎮 Usage

zwyrm help

zwyrm version

zwyrm info

# Scan directory
zwyrm scan ~/Downloads

# Quick scan
zwyrm scan -q ~/Downloads

# Full system scan
zwyrm scan -f /

# Scan and quarantine threats
zwyrm scan -r ~/Downloads

# Verbose scan
zwyrm scan -v /path/to/file

## 🔄 Signature Updates

Update malware signatures:

zwyrm update

Force update:
zwyrm update --force

## 📦 Quarantine Management

# List quarantined files
zwyrm quarantine --list

# Restore file
zwyrm quarantine --restore 3

# Permanently remove file
zwyrm quarantine --remove 5

# Clear quarantine
zwyrm quarantine --clear

## 🛡️ Real-Time Protection

# Start monitoring
zwyrm realtime --start

# Check status
zwyrm realtime --status

# Stop monitoring
zwyrm realtime --stop

Requires:
pip install pyinotify

## ⚙️ Configuration

ZWyrm uses `config.yaml` for customization.

Example configuration:

zwyrm:

  debug_mode: false
  
  log_level: INFO
  
  max_file_size: 10485760
  
  exclude_paths:
  
    - /proc
    
    - /sys
    
    - /dev
    
  scan_extensions:
  
    - .exe
    
    - .bin
    
    - .sh
    
    - .py
    
  auto_update: true
  
  update_interval: 86400

  ## 📊 Logging

Logs are stored inside the logs/ directory.

View logs in real-time:


tail -f logs/scanner.log

tail -f logs/quarantine.log

## 🔒 Security Considerations

- Avoid running the program as **root unless necessary**
- Keep malware signatures **regularly updated**
- Maintain **system backups**
- Restrict access to quarantine directories
